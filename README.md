# 논문 번역기 (Chrome 확장)

영어 논문을 읽다가 문장을 드래그하면, 선택한 곳 근처에 한국어 번역이 작은 창으로 뜨는 크롬 확장 프로그램입니다.
번역 엔진은 구글 번역(무료, API 키 불필요)만 사용합니다.

## 사용법

- **웹페이지와 PDF 모두 같습니다**: 영어 문장을 드래그하면 번역 창이 뜹니다.
- 창의 **×** 를 누르거나, **창 바깥을 클릭**하거나, **Esc** 를 누르면 닫힙니다. 스크롤하면 선택한 문장을 따라갑니다.
- 툴바 아이콘에서 "드래그하면 바로 번역"과 "PDF를 내장 뷰어로 열기"를 켜고 끌 수 있습니다.
- 번역 전에 PDF 복사 텍스트를 정리합니다: 줄바꿈 제거, `algo-\nrithm` 같은 하이픈 끊김 연결, `ﬁ`/`ﬂ` 합자 풀기.
- 한 번에 최대 5000자까지 번역합니다.

### PDF는 어떻게 되나

크롬 기본 PDF 뷰어에서는 확장 프로그램이 동작하지 않습니다. 그래서 PDF 주소를 열면 확장에 들어 있는
[PDF.js](https://github.com/mozilla/pdf.js) 뷰어(`pdfjs/`)로 자동 전환해서 엽니다.

- 주소가 `.pdf`로 끝나는 PDF, arXiv(`/pdf/2301.00001`)처럼 확장자가 없지만 `Content-Type: application/pdf`인 PDF, 로컬 `file://` PDF를 가로챕니다.
- 파일은 확장 프로그램이 직접 내려받아 뷰어에 넘기므로, 로그인한 상태(쿠키)가 필요한 논문 사이트도 열립니다.
- `Content-Disposition: attachment`(다운로드용) PDF는 건드리지 않습니다.
- 예전의 크롬 뷰어로 돌아가려면 툴바 아이콘에서 "PDF를 내장 뷰어로 열기"를 끄세요.

## 설치

1. 이 폴더를 로컬 PC로 내려받습니다 (`git clone https://github.com/YunInSung/translation.git`).
2. 크롬에서 `chrome://extensions` → 우측 상단 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택.
4. 로컬 PDF 파일(`file://`)을 열려면 확장 상세 페이지에서 **파일 URL에 대한 액세스 허용**을 켭니다.

모든 사이트의 PDF를 내려받아 뷰어에 넘기기 때문에 `http(s)://*/*` 권한을 요청합니다.
번역을 위해 외부로 나가는 것은 선택한 텍스트가 구글 번역(`translate.googleapis.com`)으로 전송되는 것뿐입니다.

## 개발

```
npm test    # 전처리·번역 로직 단위 테스트 (Node 20+)
```

- `lib/preprocess.js` — 텍스트 정리, 영어 판별
- `lib/translate.js` — 구글 번역 호출, 긴 텍스트 분할
- `background.js` — 번역 요청 처리, PDF를 내장 뷰어로 전환
- `content.js` — 드래그 감지, 번역 창 (웹페이지와 PDF 뷰어에서 공용)
- `pdfjs/` — PDF.js 6.4.299 배포본(Apache-2.0, `pdfjs/LICENSE`). 용량을 줄이려 소스맵, 샘플 PDF, 한국어·영어 외 언어 파일은 뺐습니다.
  - `pdfjs/web/reader.html` — `viewer.html`을 기반으로 `content.js`, `reader.js` 등을 끼워 넣은 것
  - `pdfjs/web/reader.js` — `reader.html?src=<PDF 주소>`를 받아 PDF를 내려받고 뷰어에서 연다

## 한계

- 구글 번역의 비공식 엔드포인트를 쓰므로 구글이 막거나 요청이 아주 많으면 실패할 수 있습니다.
- 스캔본(이미지) PDF는 텍스트를 선택할 수 없어서 번역되지 않습니다.
