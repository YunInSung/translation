# 논문 번역기 (Chrome 확장)

영어 논문을 읽다가 문장을 드래그하면 한국어로 번역해 주는 크롬 확장 프로그램입니다.
번역 엔진은 구글 번역(무료, API 키 불필요)만 사용합니다.

## 동작 방식

| 상황 | 사용법 |
|---|---|
| 웹페이지 (arXiv HTML, 저널 사이트 등) | 영어 문장을 드래그하면 선택 영역 근처에 번역 툴팁이 뜹니다. 빈 곳을 클릭하거나 Esc로 닫습니다. |
| PDF (크롬 내장 뷰어) | 텍스트를 선택하고 우클릭 → **한국어로 번역**. 팝업 창에 번역과 원문이 표시됩니다. |

- 툴바 아이콘을 누르면 "드래그하면 바로 번역"을 끌 수 있습니다. 꺼도 우클릭 메뉴는 동작합니다.
- 번역 전에 PDF 복사 텍스트를 정리합니다: 줄바꿈 제거, `algo-\nrithm` 같은 하이픈 끊김 연결, `ﬁ`/`ﬂ` 합자 풀기.
- 한 번에 최대 5000자까지 번역합니다.

크롬 내장 PDF 뷰어에서는 확장 스크립트가 실행되지 않아서 PDF는 우클릭 방식입니다.

## 설치

1. 이 폴더를 로컬 PC로 내려받습니다 (`git clone https://github.com/YunInSung/translation.git`).
2. 크롬에서 `chrome://extensions` → 우측 상단 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택.
4. 로컬 PDF 파일(`file://`)을 쓴다면 확장 상세 페이지에서 **파일 URL에 대한 액세스 허용**을 켭니다. 우클릭 번역은 이 설정 없이도 동작하지만, 켜 두는 편이 안전합니다.

## 개발

```
npm test    # 전처리·번역 로직 단위 테스트 (Node 20+)
```

- `lib/preprocess.js` — 텍스트 정리, 영어 판별
- `lib/translate.js` — 구글 번역 호출, 긴 텍스트 분할
- `background.js` — 우클릭 메뉴, 번역 요청 처리
- `content.js` — 드래그 감지, 툴팁
- `result.html` / `result.js` — PDF용 번역 결과 팝업 창

## 한계

구글 번역의 비공식 엔드포인트(`translate.googleapis.com`)를 쓰므로 구글이 막거나 요청이 많으면 실패할 수 있습니다.
